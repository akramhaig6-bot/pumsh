# منصة نَما — Frontend Only

واجهة عربية متكاملة لإدارة العروض والطلبات، مبنية بـ React وTypeScript وVite وTailwind CSS.

## التشغيل

```bash
npm install
npm run dev
```

## بناء الإنتاج

```bash
npm run build
npm run preview
```

المشروع مهيأ لـ Vercel عبر `vercel.json` مع دعم مسارات React Router.

## إعداد الإدارة

افتح `/admin/login`. عند أول استخدام تظهر شاشة إنشاء المدير الأول؛ لا توجد بيانات دخول افتراضية أو تجريبية.

## التخزين

بناءً على شرط المشروع بعدم استخدام Backend أو API، جميع البيانات التشغيلية تُحفظ في `localStorage` الخاص بالمتصفح، بما فيها الحسابات والعروض والطلبات والتذاكر والمحتوى والإعدادات. لا يحتوي المشروع على Mock Data؛ تبدأ الكيانات التشغيلية فارغة.

> ملاحظة أمنية: تطبيق Frontend-only لا يمكنه توفير مصادقة سرية أو مشاركة البيانات بين الأجهزة. للاستخدام العام متعدد المستخدمين يلزم Backend موثوق، لكن هذا المشروع يلتزم صراحة بنطاق الواجهة فقط.

## الوحدات

- الواجهة العامة والعروض والمقالات والصفحات الديناميكية.
- تسجيل العملاء والملف الشخصي وتغيير/استعادة كلمة المرور محلياً.
- الطلبات، المرفقات، استكمال المعلومات، الحالات والخط الزمني.
- تذاكر الدعم المرتبطة بالطلبات، الردود، الإغلاق وإعادة الفتح.
- إشعارات العملاء والمديرين وسجل الأحداث.
- إدارة العروض والعملاء والطلبات والتذاكر والمديرين.
- CMS: الصفحات، المقالات، التصنيفات، البنرات، الوسائط، القوائم والنصوص العامة.
- إعدادات الهوية والتواصل والوسائط والصيانة والصفحة الرئيسية.
