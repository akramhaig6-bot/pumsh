# منصة نَما — Full-Stack على سيرفر واحد

منصة متكاملة (عروض + طلبات + دعم فني + إشعارات فورية + CMS كامل) تعمل بالكامل من
خادم Node واحد: API + SQLite + WebSocket (Socket.IO) + واجهة الويب + ملفات مرفوعة.
**لا توجد أي خدمة خارجية إطلاقاً** (لا Supabase، لا Firebase، لا CDN خارجي).

## التشغيل

```bash
npm install
cp .env.example .env        # عدّل SECRET و ADMIN_PASSWORD
npm run build              # بناء الواجهة إلى dist/
npm start                  # أو: npm run dev (خادم + HMR)
```

ثم افتح `http://localhost:8080`.

- الحساب الإداري الأول يُنشأ تلقائياً من `.env` (`ADMIN_EMAIL` / `ADMIN_PASSWORD`).
- أول دخول إداري **يلزمك بتغيير كلمة المرور المؤقتة** قبل أي إجراء.
- بوابة الإدارة: `/login-admin` أو من داخل الواجهة («دخول الإدارة»).

## البنية

```
server/            # الخلفية (Express + SQLite + Socket.IO)
  db.js            # المخطط الكامل (~65 جدولاً/فهرساً)
  index.js         # نقطة الإقلاع: API + WebSocket + خدمة dist
  seed.js          # بذور: أدمن أول، صفحات، قوائم، نصوص
  routes/          # auth, public, client, admin, cms, files, uploads
  services/        # آلات الحالات (طلبات/تذاكر)، إشعارات، أحداث، إعدادات
client/            # الواجهة (React + Vite — RTL)
  src/pages/       # عام + حساب العميل + لوحة الإدارة (CMS)
dist/              # ناتج البناء الذي يخدمه السيرفر نفسه
data/              # قاعدة SQLite + الملفات المرفوعة (محلي 100%)
```

## الحماية المطبقة

- `scrypt` (salt+hash) لكلمات المرور، جلسات token عشوائي يُخزَّن هاش فقط.
- كوكي جلسة `HttpOnly/SameSite=Strict` + حماية CSRF (`nama_csrf` + `X-CSRF-Token`).
- تأمين دخول: 3 محاولات فاشلة ← كابتشا، 5 ← حظر مؤقت 15 دقيقة.
- حدود معدل عام + مشددة للمصادقة والرفع؛ تعقيم HTML لكل المحتوى؛ فحص MIME/حجم الملفات.
- مرفقات خاصة لا تُخدم إلا لصاحبها أو الأدمن؛ أثر تدقيق كامل (`events`).

## تدفقات الإدارة من لوحة `/admin`

- النظرة العامة: عدادات + قوائم ما يحتاج إجراءً.
- الطلبات: عرض، بحث، تحريك الحالة (9 حالات) مع أسباب إلزامية للرفض/الإلغاء.
- التذاكر: ردود فورية (تصل العميل عبر WebSocket)، إغلاق/إعادة فتح.
- العملاء: ملف كامل، تعطيل/تفعيل، إعادة تعيين كلمة مرور.
- المحتوى (CMS): عروض، مقالات، صفحات، تصنيفات، بانرات (مع عدّاد نقرات)،
  قوائم تنقل، نصوص عامة، مكتبة وسائط محلية، إعدادات المنصة (مع سجل تغييرات).
- النظام: إشعارات (وإعادة إرسال)، سجل أحداث + تصدير CSV، مشرفون (إنشاء/تعطيل/تعديل)، نسخ احتياطي JSON.
